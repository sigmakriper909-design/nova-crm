# Nova CRM

Современная CRM-система с красивым дизайном (Glassmorphism) и плавными анимациями (GSAP).

## Возможности

- 📊 **Панель управления** — статистика, график продаж, лента активности
- 👥 **Контакты** — таблица с поиском и статусами
- 💰 **Сделки** — канбан-доска с drag & drop
- ✅ **Задачи** — список с чекбоксами
- ⚙️ **Настройки** — профиль пользователя

## Технологии

- Чистый HTML / CSS / JavaScript
- GSAP для анимаций
- Plus Jakarta Sans
- Полностью адаптивный дизайн

## Запуск

Просто откройте `index.html` в браузере или задеплойте на любой static-хостинг.
