# Nova CRM

Современная CRM-система с красивым дизайном (Glassmorphism) и плавными анимациями (GSAP).

## 🔗 Ссылки

- **GitHub:** https://github.com/sigmakriper909-design/nova-crm
- **Live Demo:** https://nova-crm-sigmakriper909-designs-projects.vercel.app

## Возможности

- 📊 **Панель управления** — статистика, график продаж, лента активности
- 👥 **Контакты** — таблица с аватарами, статусами и суммами сделок
- 💰 **Сделки** — канбан-доска (Лид → Переговоры → Предложение → Закрыто) с drag & drop
- ✅ **Задачи** — список с чекбоксами и сроками
- ⚙️ **Настройки** — профиль пользователя

## Технологии

- Чистый HTML / CSS / JavaScript (один файл)
- GSAP для анимаций
- Plus Jakarta Sans
- Полностью адаптивный дизайн
- Glassmorphism + soft shadows

## Запуск

Просто откройте `index.html` в браузере.
